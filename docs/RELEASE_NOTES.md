# Release changes on 14 October 2026

Projector and LoRA checkpoint selection now weights clean and pooled artefact validation F1 equally, as described in the manuscript. Previously the public scripts used F1 calculated by pooling clean and artefact predictions. The new criterion is stored in saved checkpoints, and resume rejects older or unknown criteria. Both adapter trainers also select mean clean/artefact F1 at threshold 0.5 and record their criterion.

Historical experiment results and checkpoints have not been regenerated by this code update. Original run logs must establish how published checkpoints were selected; a change to release code cannot establish historical provenance.

The release adds source-image bootstrap analysis, paired comparisons and Holm correction, OpenAI/Gemini inference scripts, and the adapter trainer covering all six manuscript models. The analysis script requires saved predictions and complete comparison families. Its tests use synthetic data and do not validate the published numerical results.

Figure-generation code, final study split metadata, and actual demonstration selections are not included in this release. Example CSVs and manifests are templates. Before submission, the authors should provide the final evaluation cohort and demonstration IDs/order, plus exact model revisions and original experiment settings, through the access route stated in the manuscript. In particular, any patient exclusions used in the final OCT analysis must be reflected in those materials.
